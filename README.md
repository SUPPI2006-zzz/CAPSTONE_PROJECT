# Mamaearth Returns & Growth Intelligence Pipeline

## Project Overview

The Mamaearth Returns & Growth Intelligence Pipeline is an end-to-end data analytics project designed to analyze return drivers and determine true revenue after data cleaning.

The project uses:
- SQL for data storage and business reporting
- Python/Pandas for data cleaning, analysis, and visualization
- GenAI for presenting verified business insights
